# Редактирование меню «Каховки»

Сайт читает опубликованные записи проекта `kakhovka` (`yraqwdi0`), набор данных `production`. Для чтения меню браузер обращается напрямую к Sanity CDN. Ключ для записи на сайте не используется.

## Первый перенос меню на сайт

Файл `kahovka-sanity.ndjson` в корне проекта содержит 11 категорий и 60 блюд. Сборка сайта и запуск Studio сами по себе оставляют этот файл на компьютере. Чтобы гости увидели блюда, каталог нужно один раз загрузить в рабочую базу. Импорт записей из этого файла сразу публикует названия и цены.

Для импорта откройте PowerShell в корне проекта. Войдите в Sanity под учётной записью с правом записи в рабочую базу.

```powershell
cd sanity
.\node_modules\.bin\sanity.cmd login
.\node_modules\.bin\sanity.cmd datasets import ..\kahovka-sanity.ndjson --project yraqwdi0 --dataset production --missing
```

Параметр `--missing` пропускает существующие документы с тем же идентификатором. После первого импорта цену и состав блюд меняйте в Studio кнопкой **Publish**. Повторный импорт с этим параметром пропустит ранее загруженные блюда.

Для проверки откройте «Блюда» в Studio и разверните полное меню на сайте. Если проверяете сайт локально, установите `VITE_LOCAL_MENU_PREVIEW=false` в `.env.development.local` и перезапустите `npm run dev` из корня проекта. Тогда сайт покажет опубликованные записи Sanity. Значение `true` включает отдельный предпросмотр из файла со своим набором избранных блюд и лимитом в 16 позиций.

## Как изменить меню

1. Войдите в Studio через GitHub под учётной записью с правами редактора проекта.
2. Откройте «Блюда», выберите позицию, измените цену, описание или размер порции и нажмите **Publish**. После обновления страницы и кэша Sanity сайт покажет изменения.
3. Чтобы временно убрать позицию, выключите «Показывать в меню» и опубликуйте изменение. Так же можно скрыть категорию целиком.
4. Чтобы добавить блюдо, укажите название, категорию и цену в рублях. Поле «Порядок» задаёт последовательность внутри категории. Избранные блюда первыми попадают в краткое меню.
5. В «Настройки меню» задайте количество блюд до раскрытия списка. Кнопка раскрытия появляется, когда опубликованных блюд больше этого числа.

## Локальный запуск

Сайт запускается командой `npm run dev` из корня проекта. Редактор запускается отдельно командой `npm --prefix sanity run dev`. На новом компьютере сначала установите зависимости командами `npm ci` и `npm --prefix sanity ci`.

Проект и набор данных заданы в конфигурации. Для другого окружения скопируйте соответствующий файл `.env.example` в `.env.local` в корне сайта и в каталоге `sanity`. Переменные в этих файлах содержат публичный идентификатор проекта и имя набора данных.

Для локальной сверки с предоставленным каталогом задайте VITE_LOCAL_MENU_PREVIEW=true в .env.development.local в корне сайта. В этом режиме Vite читает kahovka-sanity.ndjson. Производственная сборка запрашивает опубликованные данные Sanity. Для прямого запроса из браузера домен сайта должен быть добавлен в CORS origins проекта без учётных данных.
